# tuscany-sunset

Caio on a stone wall, watching the sun sink into the sea: a dusk teal
dark theme with a sunset orange accent and dark cyan water.

- `colors.toml` - the palette every fragment is generated from
- `hyprland.conf` - hand-tuned window manager styling (borders, rounding)
- `backgrounds/` - the sunset wallpaper
- `preview.png` - what pickers and the catalog show

```bash
riso theme install tuscany-sunset
riso theme set tuscany-sunset
```
